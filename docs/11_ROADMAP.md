# Roadmap — Under One Roof

## Phase 0 — Foundation

Goal: Create product and technical foundation.

Tasks:

- Define product brief
- Create GitHub repo
- Create React/Vite project
- Add TypeScript
- Add Tailwind
- Add routes
- Add CLAUDE.md
- Create README
- Deploy initial landing page

## Phase 1 — Frontend MVP With Mock Data

Goal: Build the visible product experience.

Features:

- Landing page
- Auth placeholder
- Onboarding wizard
- Dashboard
- Bills page
- Contracts page
- Documents page
- Maintenance page
- Repairs page
- AI assistant placeholder
- Settings page

## Phase 2 — Real Auth & Database

Goal: Make data persistent.

Features:

- User accounts
- Home profiles
- Create/read/update/delete bills
- Create/read/update/delete contracts
- Create/read/update/delete maintenance tasks
- Basic document upload

## Phase 3 — Insights & Reminders

Goal: Make the app proactive.

Features:

- Upcoming bill reminders
- Contract renewal alerts
- Maintenance reminders
- Overdue status
- Suggested actions
- Simple home health score

## Phase 4 — AI Assistant Lite

Goal: Let users ask questions about structured home data.

Questions supported:

- What bills are due soon?
- What contracts renew soon?
- What maintenance is overdue?
- What documents do I have?
- What should I do this month?

## Phase 5 — Document AI

Goal: Extract useful information from uploaded documents.

Features:

- Extract text from PDFs
- Summarize lease/contracts
- Extract dates
- Extract costs
- Extract renewal/cancellation terms
- Create suggested reminders from documents

## Phase 6 — Negotiation Assistant

Goal: Help users save money.

Features:

- Detect upcoming renewal windows
- Bill increase alerts
- Negotiation scripts
- Renewal comparison checklist
- Cancel/keep guidance

## Phase 7 — Renter Toolkit

Goal: Strong renter-specific value.

Features:

- Move-in photo documentation
- Move-out checklist
- Security deposit tracker
- Landlord message templates
- Lease review reminders

## Phase 8 — Homeowner Toolkit

Goal: Strong homeowner-specific value.

Features:

- Seasonal maintenance plans
- Contractor history
- Repair cost history
- Warranty tracking
- Home inventory
- Emergency mode

## Phase 9 — Mobile App Path

Goal: Prepare for app stores.

Options:

- Progressive Web App first
- React Native/Expo later
- Native app only after web app proves demand

## Phase 10 — Business Expansion

Possible future revenue:

- Freemium app
- Paid personal plan
- Family plan
- Landlord plan
- Property manager plan
- Contractor partnerships
- Insurance/warranty affiliate partnerships
- Real estate agent onboarding partnerships
